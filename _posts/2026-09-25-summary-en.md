## [Whiteboard: Open-Source IDE for Collaborative Software Design with AI](https://github.com/devdotfast/whiteboard) ⭐️ 8.0/10

Whiteboard, an open-source desktop IDE, has been released, enabling humans and AI agents to collaboratively architect software within a shared visual workspace. It integrates with existing tools like Claude Code and Codex, offering an SDK for AI agents to draw on an in-app canvas. This IDE addresses the challenge of maintaining code comprehensibility and managing cognitive debt when working with AI coding agents, potentially improving developer productivity and collaboration in AI-assisted software development. Built on CodeOSS, Whiteboard allows direct navigation between diagrams and code, features a semantic, AST-aware diff viewer written in Rust with a WASM plugin system, and includes a Decision Log for tracing AI agent decisions.

**Background**: CodeOSS is the open-source project that Visual Studio Code is based on, providing core editor functionalities. Claude Code and Codex are AI models or tools designed to assist with software development tasks, with Codex specifically focusing on code generation and understanding.

## [OpenAI Launches MentalHealthBench to Evaluate AI in Mental Health Conversations](https://openai.com/zh-Hans-CN/index/introducing-mentalhealthbench/) ⭐️ 8.0/10

OpenAI has released MentalHealthBench, an open benchmark developed with over 80 licensed mental health professionals from 22 countries to assess AI responses in real-world mental health conversations. This benchmark is significant as it provides a standardized way to evaluate AI's capabilities and safety in the sensitive domain of mental health, potentially guiding future development and ensuring responsible AI deployment. The benchmark measures AI's performance in areas like safety, information gathering, user autonomy, and providing actionable advice, covering scenarios for adults, adolescents, caregivers, and clinicians, with results indicating AI progress but not replacing professional therapy.
