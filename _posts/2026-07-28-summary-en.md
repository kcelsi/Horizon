Security researcher Kirill Firsov has disclosed a critical remote code execution (RCE) vulnerability affecting Fastjson 1.x versions 1.2.68 through 1.2.83. This vulnerability is exploitable without requiring specific configurations like autoTypeSupport or classpath gadgets and impacts multiple JDK versions including 8, 17, and 21. This vulnerability is significant because Fastjson 1.x is a widely used Java JSON parsing library, and the flaw allows unauthenticated RCE, posing a severe risk to applications. Given that Fastjson 1.x is end-of-life and no official patch is expected, affected users must urgently migrate to Fastjson2 or implement mitigation strategies. The vulnerability, tracked as CVE-2026-16723 with a CVSS score of 9.0, is exploitable across various JDK versions (8, 17, 21) without needing specific configurations or gadgets, and active exploitation has been detected. The only official recommendation is to upgrade to Fastjson2 or apply specific startup parameter and configuration mitigations.

Remote Code Execution (RCE) is a type of vulnerability that allows an attacker to execute arbitrary code on a remote machine.

China's semiconductor manufacturer SMIC is currently testing the first advanced deep ultraviolet (DUV) lithography machine developed by Shanghai SMEE, with most components now domestically produced. This development is significant for China's semiconductor industry as it represents a step towards reducing reliance on foreign lithography equipment, potentially impacting global supply chains and China's technological self-sufficiency goals. SMIC is using the machine to produce 28nm chips and is exploring multi-patterning techniques to potentially achieve 7nm, and even 5nm at low yields, though mass production of domestic machines is not expected until 2027.

Advanced nodes like 7nm and 5nm typically require more sophisticated techniques such as multi-patterning, which involves multiple exposure and etching steps, or the even more advanced Extreme Ultraviolet (EUV) lithography, which China currently cannot access due to export controls.
