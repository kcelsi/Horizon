Firefox is now the only major web browser that continues to fully support uBlock Origin, a popular content blocker, following changes in other browsers that have restricted extension capabilities. This distinction is significant for users prioritizing privacy and an ad-free browsing experience, as it highlights a divergence in browser development philosophies regarding extension control and user freedom. Other browsers, particularly those based on Chromium, are moving towards Manifest V3, which limits the capabilities of ad-blocking extensions like uBlock Origin by restricting the webRequest API. ## [Doom's Renderer Compiled into 21B Transformer Without Training](https://www.reddit.com/r/MachineLearning/comments/1voazhm/i_compiled_dooms_renderer_into_a_21bparameter/) ⭐️ 8.0/10

A 21 billion parameter transformer model has been created by compiling Doom's rendering algorithm directly into its weights using a custom compiler, bypassing traditional machine learning training methods. The model outputs pixel drawing commands that, when executed, reconstruct the rendered frame. This novel approach demonstrates a new paradigm for creating large AI models by directly embedding algorithms, potentially enabling more efficient model creation and novel applications by treating code as data for transformers. The model generates a sequence of 53,747 tokens representing drawing commands, requiring a 3,614-token prompt and taking 40 minutes on a B200 GPU, achieving approximately 0.04 frames per second. The generated checkpoints are compatible with Hugging Face's standard transformers library and can be loaded without `trust_remote_code`.

The release is significant for its parameter efficiency in large-scale MoE models and its extensive context handling capabilities, potentially advancing research in efficient LLM architectures and long-context understanding. Dots3-note was trained using a novel reinforcement learning method called TEMPO, which involves self-critique and at-test-time value estimation for training long-range agents. A 512K context window refers to the model's ability to process and understand very long sequences of text or data, equivalent to 512,000 tokens.

## [PostgreSQL Fixes Critical to_char Vulnerability Allowing Arbitrary Code Execution](https://www.postgresql.org/support/security/CVE-2026-14669/) ⭐️ 8.0/10

PostgreSQL has released updates to fix a critical vulnerability (CVE-2026-14669) in the to_char(timestamptz) function. This vulnerability could allow a database user with timezone setting privileges to execute arbitrary code with the permissions of the PostgreSQL service process. This vulnerability, with a CVSS score of 8.8, poses a significant security risk to PostgreSQL deployments. While requiring low-level database privileges to exploit, it could lead to full system compromise if leveraged successfully. The vulnerability stems from a heap buffer overflow when processing overly long POSIX timezone abbreviations. Affected versions include those prior to PostgreSQL 18.5, 17.11, 16.15, 15.19, and 14.24. Updates are available, and applying them requires only restarting the service, not a database dump or pg_upgrade.

telegram · zaihuapd · Aug 14, 14:35

**Background**: A heap buffer overflow occurs when a program writes more data into a memory buffer allocated on the heap than the buffer is designed to hold. This can corrupt adjacent memory and potentially allow an attacker to overwrite critical data or control program execution. The Common Vulnerability Scoring System (CVSS) is a framework for assessing the severity of security vulnerabilities.
