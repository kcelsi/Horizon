## [Linux Zoom Client Reads X11 Clipboard Proactively, Sparking Privacy Concerns](https://hachyderm.io/@simontatham/117201594980991062) ⭐️ 8.0/10

The Linux version of the Zoom client has been discovered to proactively read all data from the X11 clipboard, even when not actively pasting. This behavior was identified and reported by users, raising immediate privacy and security alarms. This proactive clipboard access by Zoom on Linux systems represents a potential privacy breach, as sensitive information copied by users could be read without their explicit action. It highlights a broader issue of application privilege escalation and data handling practices within the software ecosystem. The issue specifically affects the X11 display server environment on Linux, where applications can, by design, query the clipboard's contents. While X11's clipboard mechanism allows this, Zoom's proactive reading, rather than waiting for a paste command, is the point of concern.

hackernews · encyclopedism · Sep 12, 18:58 · [Discussion](https://news.ycombinator.com/item?id=49675902)

**Background**: The X Window System (X11) is a windowing system for bitmap displays, common in Unix-like operating systems. Its clipboard mechanism allows data transfer between applications by having one application 'own' the clipboard and provide data when another application requests it. However, the copying application doesn't send data to the X server but rather informs it that it owns the clipboard.
