## [Reladraw: Diagram Language Blending Code Expressiveness with Visual Control](https://github.com/reladraw/reladraw) ⭐️ 8.0/10

Reladraw is a new diagram language that offers the expressiveness of code-based diagramming tools while providing the visual control typically found in manual drawing applications. It is designed for usability by both humans and AI agents, with a playground available for testing and instructions for npm installation and agent integration. This innovation addresses a significant gap in diagramming tools, which often force a choice between automated layout and manual precision, making it crucial for AI-assisted development and complex system planning. It could improve collaboration between developers and AI agents by providing a more intuitive and controllable way to represent architectural and logical structures. Reladraw aims to balance the benefits of text-based diagramming languages like Mermaid and Graphviz, which can be inefficient for precise visual layout, with the detailed control of tools like Draw.io, which can be time-consuming. The project emphasizes relative positioning to achieve a desired look without sacrificing agent manipulability.

## [China Launches 'Space String' Plan for Global Deep-Space Computing Infrastructure](https://www.ithome.com/1/007/486.htm) ⭐️ 8.0/10

China has announced the 'Space String' computing constellation plan, aiming to establish a space-based computing infrastructure for global and deep-space applications. The plan involves phased deployments starting with a verification satellite in Q4 2027, followed by standard and flagship satellites. This initiative represents a significant step towards creating a distributed, space-based computing network, potentially enabling new capabilities for AI, data processing, and communication in remote or challenging environments. It could impact the development of future space-based AI and distributed computing architectures. The constellation will comprise over 720 data satellites for acquisition and over 360 computing satellites for training, interconnected via inter-satellite laser links to enable collaborative resource scheduling.

**Background**: A satellite constellation is a group of artificial satellites working together as a system. Inter-satellite laser links (LISLs) are a form of free-space optical communication used to connect satellites directly, enabling faster and more secure data transfer within the constellation, similar to how SpaceX's Starlink utilizes them.
