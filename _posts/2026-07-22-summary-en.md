## [Jacobian Conjecture Disproven by Explicit Counterexample](https://terrytao.wordpress.com/2026/07/21/a-digestion-of-the-jacobian-conjecture-counterexample/) ⭐️ 8.0/10

A counterexample to the Jacobian conjecture has been found and detailed, disproving a long-standing mathematical problem for N > 2 dimensions. This counterexample was discovered using Anthropic's Claude Fable 5 large language model. This disproof resolves a significant open problem in algebraic geometry, potentially impacting fields that rely on polynomial invertibility assumptions. The use of AI in discovering this mathematical counterexample also highlights a new frontier in computational mathematics research. The counterexample involves a polynomial function in three dimensions where the Jacobian determinant is a non-zero constant, yet the function does not possess a polynomial inverse. The construction of the polynomial exhibits a massive cancellation of coefficients, making verification complex.

hackernews · jeremyscanvic · Jul 21, 21:09 · [Discussion](https://news.ycombinator.com/item?id=48998362)

**Background**: The Jacobian conjecture, first stated in 1884 and restated in 1939, posits that if a polynomial function from N-dimensional space to itself has a non-zero constant Jacobian determinant, then it must have a polynomial inverse. It remained an open problem, notorious for numerous incorrect proofs, and was listed as one of Smale's 1998 problems for the next century.

## [Federated Learning Accuracy Masks Minority Data Silo Failures](https://www.reddit.com/r/MachineLearning/comments/1v32mfs/my_federated_learning_project_just_showed_that/) ⭐️ 8.0/10

A federated learning project demonstrated that high overall accuracy (96%) can deceptively hide a model's complete failure (0.00 recall) to detect attacks in a minority data silo with extreme imbalance, while FedNova showed consistent high performance across all silos. This highlights a critical flaw in relying solely on aggregate accuracy metrics in federated learning, especially for imbalanced datasets, potentially leading to overlooked security vulnerabilities in real-world applications. The minority 'Web Attacks' silo had only 3k samples out of 3 million total, and even a centralized baseline model showed unstable performance on this silo across different random seeds, whereas FedNova proved robust.

reddit · r/MachineLearning · /u/Initial-Street6388 · Jul 22, 02:08

**Background**: Federated learning (FL) is a machine learning technique that trains an algorithm across multiple decentralized edge devices or servers holding local data samples, without exchanging them. FedAvg is a common FL algorithm that averages model weights from clients to create a global model. Data imbalance occurs when the distribution of data samples across different classes or groups is uneven.
